# パターンマッチ指向証明：言語設計

## 現在の状況（2026-10-09）

Egison Prover は、**数学的な構造の選択・分解を、定理の主張と証明の途中で
同じパターン言語によって記述する**証明言語を目指す。

本ファイルと各 `pwl-*.md` は現在の設計案である。
全例の定義・補助補題・証明を含む Lean 版とパターンマッチ指向版は
[design/examples/](examples/README.md) に置く。
通常の Lean 版と、パターンの証拠を明示した Lean 版を Lean 4.31.0 / Mathlib v4.31.0 で検査する。
`.pmop` は完全な提案ソースであり、現在の処理系では直接検査できない。
`sample/pmop/` はこの完全なコードを参照する入口とする。
Haskell 実装は `sample/*.pegi` の構文を扱う依存型検査器の試作で、
`matches`、`exhaustive by`、ここで提案するマッチャーは未実装である。
実装済みの構成と、検査器・証明規則を完成させる作業は
[review.md](review.md) に記す。

以下で、マッチャー（matcher）はパターンの解釈と対象の分解方法を与えるもの、
ターゲット（target）は照合される値を指す。
`$x` はマッチした値を束縛するパターン変数、`_` は値を束縛しないワイルドカード、
`#e` は式 `e` と等しい値を要求するバリューパターンである。
先に束縛した変数を `#x` で参照する形を非線形パターンと呼ぶ。
`Fin n` は `0, …, n−1` の有限型、`Sym2 A` は `A` の順序なしペアの型である。
多重集合（multiset）は順序を区別せず重複を数える容器、集合（set）は同じ要素の重複を
区別しない容器、リスト（list）は順序と重複を持つ列である。

## 背景と動機

Egison のパターンマッチは、集合や多重集合など、構成方法を一意に決められない
対象からも、条件を満たす要素や部分構造を選べる。
パターンとマッチャーに型を与える研究を基礎に、この記述方法を証明へ広げる。
証明では、選んだ値だけでなく、その値と元の対象との関係の証拠を取り出し、
次の推論へ渡す必要がある。

例えば Ramsey R(3,3)=6 の存在側は、6頂点の完全グラフの任意の2色塗りが
単色三角形を含むことを、次のパターンで表す。

```egison
theorem ramsey_six (edge : Sym2 (Fin 6) → Color) :
    edge matches ($x, $y) → $c :: (#y, $z) → #c :: (#z, #x) → #c :: _
    as multiset (Sym2 (Fin 6) → Color)
```

`(p₁, p₂) → p₃` は彩色関数の入出力ペアを観察し、`::` はそのペアを
多重集合から取り出す。ここでのペアパターンは両端が異なる辺を選び、
繰り返す頂点と色を `#x`、`#y`、`#z`、`#c` で指定する。
これらの意味はマッチャーの関係として定義し、相異性・辺の所属・色の等式の
証拠を各腕に渡す。

この記述方法により、次の操作を一つのパターンで表せる。

- 条件を満たす要素や部分構造の存在を述べる。
- 証明からその構成要素と、等式・所属・分解の証拠を取り出す。
- 証明の途中で同じ分解を使い、等式変形や帰納仮定の適用へ進む。

### 主張と適用の一致：具体例

[Ramsey の証明](pwl-ramsey.md) では、頂点 `v` を固定した
補題 `pigeonhole_edges_at` の主張側のパターン

```egison
edge matches (#v, $x) → $c :: (#v, $y) → #c :: (#v, $z) → #c :: _
    as multiset (Sym2 (Fin 6) → Color)
```

を、主定理の証明中の `match hstar : edge as …` の腕にも使う。

```egison
| (#v, $x) → $c :: (#v, $y) → #c :: (#v, $z) → #c :: _ =>
    rcases hstar with ⟨hvx, hvy, hvz, hxy, hxz, hyz, evx, evy, evz⟩
```

`exhaustive by pigeonhole_edges_at edge v` は、この分解の存在の証拠を与える。
主張では存在命題として、適用では値と関係の証拠を取り出す操作として、
同じパターンを使う。変数名の変更やワイルドカードの束縛なども、
パターン間の証拠の変換として扱う（[review.md](review.md) §4）。

## 適用範囲：構造の選択・分解を含む推論

適用範囲は、**証明のどの段階で、どの構造を選択・分解するか**によって考える。
結論が存在命題である場合だけでなく、等式、要素数の性質、帰納的な構成の
証明にも同じ操作が現れる。記述量の差に加え、分解で得られる関係を
後続の推論へ一貫して渡せることを評価する。

### 組合せ的存在定理

条件を満たす配置や部分構造の存在を述べる定理には、さまざまな分野の例がある。

- グラフ理論：Ramsey、Hall、Dilworth、König。
- 数論的組合せ論：Schur、van der Waerden、Erdős–Ko–Rado。
- 形式言語と計算理論：pumping lemma、Myhill–Nerode。
- 順序理論：Dilworth、Mirsky。
- 加法的組合せ論：Cauchy–Davenport。
- 離散幾何：Sperner、Helly の有限版。

中心例では、対象に合うマッチャーを選び、パターンが構成要素と関係を表し、
数え上げや各分野の補題がその分解の存在を保証する。

| 定理 | 対象と分解方法 | 存在を保証する条件・推論 | 取り出す構造 |
|---|---|---|---|
| Ramsey | 辺の多重集合 | 固定頂点の5辺に同色3辺があることと、残りの三角形の色の場合分け | 単色三角形 |
| Schur | 彩色関数を集合として観察 | {1,…,5} の2色塗りの色の場合分けと加法の関係 | x, y, x+y が同色の三つ組 |
| Pumping | DFA（決定性有限オートマトン）の走行リスト | 入力長が状態数以上であることと、ループの反復による受理保存 | 非空な区間を反復できる語の分解 |
| 一般の Hall | 二部グラフの部分集合とマッチング | 任意の左側部分集合の隣接先が、その部分集合以上の大きさを持つ Hall 条件 | 左側を覆うマッチング |

### 等式変形と帰納法の途中

[固定点のない対合](pwl-involution.md) では、有限集合から x と σ(x) を
取り出す。残りも σ によって保たれることと、要素数が2減ることを証明し、
帰納仮定を適用して元の集合の要素数が偶数であることを示す。
同じ分解は、対になる重みが打ち消し合う有限和の等式にも使える。

[証明の途中で使うパターン](pwl-proof-steps.md) には、次の例がある。

| 例 | 選択・分解 | 後続の推論 |
|---|---|---|
| 群の語の逆元消去 | 前後の列と、隣り合う g, g⁻¹ | 積の等式を変形する |
| 有限置換の互換への分解 | a → b、c → a と残りのグラフ | 変換した置換の条件と対象の減少を示し、帰納仮定を使う |
| 歩道からの道の構成 | 同じ頂点を2回通る位置と、その前後の列 | 始点・終点・辺を保って区間を除去し、短い歩道に帰納仮定を使う |
| [隣接する同一要素の消去の局所合流性](pwl-local-confluence.md) | 同じ語に対する2箇所の一致・重なり・分離 | 両結果から共通の語への消去を構成する |
| [逆元対の全候補](proof-brevity.md) | 順序を保つ、互いに重ならない対を証拠とともに列挙 | すべての結果の積と長さを証明し、再帰結果にも証拠を保持する |

マッチで得た証拠は、等式を書き換えるためにも、残りが帰納仮定の前提を
満たすことを証明するためにも使う。この共通の操作を、分野の異なる例で検証する。

記述の短縮を狙う条件は [証明の短縮についての考察](proof-brevity.md) にまとめる。
複数の選択・分解の各結果に同じ推論を適用し、分解の証拠を結果や帰納仮定へ引き継ぐ場面が有望である。
逆元対の全候補では、その仕組みを有限列挙の組合せとして Lean で検査する。
同じ補題と自動化を使う Lean でも短く書けるため、パターンの記法と、証拠の再利用による効果を分ける。

## 繰り返す値を非線形パターンで表す

鳩の巣原理が与える「異なる位置に同じ値が現れる」という結論は、
`$x` と `#x` の組で直接記述できる。
Ramsey の同色辺と pumping lemma の同状態への再訪を、対象の順序の違いに
応じて multiset と list のマッチャーで表す。

```egison
-- Ramsey：固定頂点からの同色3辺
(#v, $x) → $c :: (#v, $y) → #c :: (#v, $z) → #c :: _
-- Pumping：走行列の異なる2位置で同じ状態を訪れる
_ ++ $q :: _ ++ #q :: _
-- Schur：加法で関係する3入力の色が同じ
$x → $col :: $y → #col :: #(x+y) → #col :: _
```

非線形パターンは繰り返す値の関係を表し、数え上げの証明がその存在を保証する。
Ramsey の三角形、Schur の加法関係、pumping の受理保存まで導く際には、
その関係に各分野の補題を組み合わせる。
Hall では、近傍を含む部分集合を表す `⤳` と、マッチングを取り出す
`matching_of` により、マッチャーが定理の主張と証明で使う語彙を拡張する。

## 実装方針

既存の Haskell 試作を基に、証明項を最終的に検査する小さな核
（カーネル）と、パターンによる記述を核の証明項へ変換する処理を整備する。
パーサは現在 Parsec を使い、構文木、環境、型検査・評価の実装は
`src/Language/EgisonProver/` にある。
まず既存の検査器の形成規則、変数束縛、再帰・帰納型の検査を補強し、
その上に `matches` と証拠の取り出しを実装する。
具体的な不足と完了条件は [review.md](review.md) §2–4 に記す。

## 核言語の設計

### ベース

- 依存関数型（Π 型）`(x : A) → B`：結果の型 B が入力値 x に依存する関数の型。
- 依存対型（Σ 型）`Σ x : A, B`：値 x と、その値に依存する値または証拠の組。
- 宇宙の階層：型を要素として持つ型をレベルで区別する。
  試作の `UniverseE n` は `Universe (n+1)` を型とする。
  `Type` の省略記法、Π・Σ・帰納型・`matches` の宇宙レベルと、レベル間の型の扱いは
  [review.md](review.md) §3.3 で確定する。
- 帰納型：データコンストラクタによる値の構成と、それに従う帰納法を持つ型。
- 命題等式 `Id A x y`：A の値 x と y が等しいことの証拠の型と、その証拠の除去規則。

### パターンを使う証明規則

#### 1. `e matches P as M` 命題

パターン P が束縛する値の組の型を `Bindings(P)`、その値と e の関係を
`MatchRel(M, P, e, b)` とすると、意味は次の依存対型で与える。

```text
Σ b : Bindings(P), MatchRel(M, P, e, b)
```

`Bindings` と `MatchRel` は説明用の名前であり、利用者が書く構文ではない。
束縛の型は先に選んだ値に依存できる。
`#e` は等式の証拠を、`::` は選んだ要素と残りによる分解の証拠を含む。
否定パターンや条件付きパターンの証拠も、この関係として定義する。
主張側での `matches` の構成と、証明側での `match` は、同じ証拠を扱う。

#### 2. 数学的な対象に応じたマッチャー

- **`multiset`**：順序なし、重複あり。選んだ要素を取り除いた残りを返す。
- **`set`**：順序なし。選んでも対象が減らないので、同じ要素を再び選べる。
  Schur の x = y を許す主張に使う。
- **`list`**：順序と重複を持つ列。分解の位置・順序・区間長の証拠を与える。
- **`Sym2`**：順序なしペア。辺を観察するパターンでは両端の相異性を要求する。
- **`bipartite_graph` / `matching_of`**：二部グラフの近傍の条件や、
  左側を覆うマッチングの関数と証拠を扱う。

これらを標準の分解機構として提供する。
対象型、残りの型、各腕が受け取る関係の証拠は
[コードの仕様](examples/README.md) に揃える。
有限関数の観察で残りを束縛した場合は、全関数ではなく入出力ペアの多重集合を返す。
`matching_of` の専用規則は、グラフからマッチングの関数と証拠を選ぶ。
これらの関係と証拠を核の型として構成する処理を実装する。

#### 3. `exhaustive by lemma` 構文

`lemma` は、対象 e が各腕のパターンのいずれかにマッチすることを証明する。
各腕は、その選択肢の束縛値と、h に名付けたマッチ成立の証拠を受け取り、必要な結果を返す。
通常の `match` は、この証拠に対する場合分けから導く。

```egison
match h : e as M with
| p₁ => b₁
| p₂ => b₂
exhaustive by lemma
```

腕の環境には、パターン変数だけでなく、等式・不等式・所属・分解の証拠を置く。
パターンの構造から得られる関係は、マッチ成立の証拠から自動的に導出する。
`exact ⟨束縛値⟩` は、この環境と証明済みの補題から関係の証明項を自動構成し、核で検査する。
`by proof` を付けてその構成を明示することもでき、完全な例では証拠の対応を読めるようにする。
結果の型が対象や束縛値に依存する場合の型付けも定義する。
複数のマッチが成立する場合の選択と、証拠を用いる場合分けと探索による実行の
対応は [review.md](review.md) §3.1 で扱う。

#### 4. バリューパターン `#(expr)`

式と等しい値を要求する。`#(x+y)` や `#(σ x)` を使って、算術・写像で
関係する構成要素を同じ分解の中で選べる。
Schur では彩色関数の有限グラフを自然数のキーで観察し、和も自然数として計算する。
範囲外の和はグラフに所属せず、その分解は成立しない。
通常の `#e` では、照合する値と式 e の型が一致することを検査する。

#### 5. 派生値への `matches`

ターゲットは定理パラメータだけでなく、それから計算した値でもよい。
pumping lemma の `(M.run w).take (|Q|+1)` のように、計算過程の中間値にも
パターンを使う。対象型の一致に加えて、走行列の分解と入力語・状態遷移を結ぶ
証拠を補題から導出する。

#### 6. 各結果の証拠を保持する `matchAll`

`matchAll h : e as M with | P => body` は、成功する各分解の値と関係の証拠を腕に渡す。
腕で結果とその性質の証明を組にすれば、その性質を保持する結果のリストを得られる。
対象を覆うことは要求せず、成功する分解の列挙の正しさと完全性をマッチャーの規則から証明する。
腕がリストを返す場合はリストのリストになるため、連結には `List.flatten` を明示する。
[逆元対の全候補](proof-brevity.md) では、有限リスト上の選択・条件判定・入れ子の列挙と、
証拠を取り除いた通常の列挙への対応を検査する。構文からその構成への変換は実装する必要がある。

## 健全性と実行

証明の健全性には、次の各段階の保証が必要である。

1. 核の形成・導入・除去規則、宇宙、帰納型、再帰を検査し、完成した証明では穴を拒否する。
2. 各パターンの関係とマッチャーの分解が一致し、結果と証拠に型が付く。
3. `matches` と `exhaustive by` を核の証明項へ変換した結果が型検査を通る。
4. 探索してマッチを実行する場合、その結果が関係を満たし、必要な分解を取り出せる。

実行が型に従うことと、偽の命題を証明できないことは、別々に保証する必要がある。
基礎体系の条件と各変換の正しさを揃え、言語全体の健全性を示す。

`#e` の論理的な意味は命題等式で与える。
証拠から値を取り出す際は、等式を計算で判定できることを前提にしない。
探索で `#e` を判定する場合は等式の決定可能性が必要であり、`decide` で
存在・不成立を証明する場合は、候補の列挙と判定の停止・完全性も必要になる。
多重集合・集合・リストには Egison の分解方法を活かし、型と証拠の検査を加える。
専用の構造を扱うマッチャーにも同じ保証を与える。

## 実装・形式化する例

### 中心的な例

- **[Ramsey R(3,3) = 6](pwl-ramsey.md)**：多重集合の辺、同色の関係、主張と適用の一致。
  K₆ の存在証明と K₅ の反例を揃える。
- **[Schur S(2) = 4](pwl-schur.md)**：集合による再選択と `#(x+y)`。
  {1,…,5} の存在証明と {1,…,4} の反例を揃える。
- **[Pumping lemma](pwl-pumping.md)**：順序付きの走行列と派生値の分解。
  ループの反復による受理保存まで証明する。
- **[一般の Hall の結婚定理](pwl-hall.md)**：`⤳` による Hall 条件と、
  `matching_of` によるマッチングの関数・証拠の取り出し。

[一般の鳩の巣原理](pwl-pigeonhole.md) の完全なコードも含める。
Ramsey の数え上げ、一般の関数の衝突、走行列の重複の証拠を、提案言語の分解へ接続する。

### 等式・帰納法の途中で使う例

- **[固定点のない対合](pwl-involution.md)**：対の分解、残りの閉性と減少、偶数性と有限和の等式。
- **[群の語・有限置換・歩道](pwl-proof-steps.md)**：前後の列と残りの対象を取り出し、
  等式変形、条件を保つ再構成、帰納法へ進む。
- **[局所合流性と合流性](pwl-local-confluence.md)**：2つの分解を同時に照合し、
  書換え箇所の位置関係から共通の消去先を構成する。完全な両版を比較すると、
  同じ補助補題を使う Lean 版も短く書けるため、この例では証明全体の記述量は減らない。
- **[逆元対の全候補と短縮の条件](proof-brevity.md)**：分解の証拠を列挙結果に保持し、
  同じ等式変形を各結果へ適用する。任意の個数への再帰的な拡張、通常の列挙との等式、
  自動化した Lean の比較対象も含める。

### さらに扱う例

- **[Erdős–Szekeres](pwl-erdos-szekeres.md)**：list マッチャーで入力位置の順序を保つ。
  5項の場合は有限型の証明と相対順序への帰着を含む完全なコードを置く。
  任意の線形順序と5項以上の列に対して検査する。一般の r,s による定理へも広げる。
- **Dilworth**：順序の関係を持つ対象の分解。
- **Sperner**：単体分割と彩色の条件。
- **van der Waerden の小ケース W(2,3) = 9**：等差数列の存在。

## 関連研究と評価

Egison の多重集合・集合・リストのパターンマッチと、その型システムを基礎とする。
依存型のパターンマッチ（Coq の Equations、Agda など）、補助的な観察結果に基づく
場合分け、証明支援系の分解用パターンと比較する。
さらに、パターンと命題を対応させる matching logic、Curry の関数を使うパターン、
F#・Scala の分解機構、結合律・交換律に従うマッチングとの関係を整理する。
比較項目と文献調査は [review.md](review.md) §5 に記す。

評価では、定理の分野に加えて、証明の中での役割を比較する。
存在の主張、証拠からの値の取り出し、等式変形、帰納仮定への受け渡しを、
同じパターンと証拠の規則で扱えることを示す。
主張との対応、必要な補助述語、検証済みの証明での記述量と実行・検査のコストも測定する。
比較には [完全なコード](examples/README.md) を使い、定義・補助補題・主証明を同じ範囲で数える。
主張の記述、証拠の取り出し、等式変形、帰納仮定への引き継ぎを分けて評価する。

## 主たる貢献

1. **定理の主張と証明で共通に使うパターン言語**：構造の存在と、値・関係の証拠の取り出しを対応させる。
2. **繰り返す値や関係を直接書く記法**：非線形パターンとバリューパターンで、
   鳩の巣の結論、同色の配置、算術・写像の関係を表す。
3. **マッチャーによる数学的な語彙の拡張**：一般の Hall の近傍の条件とマッチングのように、
   対象に合う分解を主張と証明に使う。
4. **証明に基づく網羅性**：`exhaustive by` の証拠から場合分けを正当化し、各腕へ関係の証拠を渡す。
5. **等式変形と帰納法への適用**：分解で得た関係を、対象の再構成、条件の保存、
   小さくした対象への帰納仮定の適用までつなげる。
