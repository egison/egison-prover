# 固定点のない対合：パターンによる分解を使う帰納法

有限集合の要素数が偶数であることを、関係を持つ2要素と残りを
パターンで取り出して証明する。定理の結論は数値的な性質であり、
証明の途中の分解にパターンを使う例である。

本ファイルの宣言と証明記述は提案言語の設計スケッチである。
`Finset A` は A の有限部分集合、`Multiset A` は多重集合を表す。
マッチャーはパターンの解釈と対象の分解方法を与えるもの、
`$x` は値を束縛するパターン変数、`#e` は式 e と等しい値を要求する
バリューパターンである。`[]` は空、`::` は多重集合から1出現を取り出す。
これらの記法と証拠の受け渡しを処理系に実装する作業は、
[設計上の課題](review.md) §3・§4 に記す。

## 1. 定理と仮定

型 A の有限部分集合 S と写像 σ : A → A を考える。
すべての x ∈ S について、次を仮定する。

\[
\sigma(x)\in S,\qquad
\sigma(\sigma(x))=x,\qquad
\sigma(x)\ne x.
\]

二度適用すると元に戻る写像を **対合（involution）** と呼ぶ。
σ(x) = x となる要素が **固定点** であり、ここでは固定点がない。
第1の仮定は、σ によって S の外へ出ないことを表す。
A 全体の有限性は要求せず、S が有限であればよい。

証明する結論は

\[
2\mid |S|,
\]

すなわち、ある自然数 k について |S| = 2k である。
$|S|$ は S の要素数を表す。

```text
theorem involution_card_even
    (S : Finset A) (σ : A → A)
    (h_closed : ∀ x ∈ S, σ x ∈ S)
    (h_invol : ∀ x ∈ S, σ (σ x) = x)
    (h_no_fixed : ∀ x ∈ S, σ x ≠ x) :
    2 ∣ card S
```

## 2. 空集合または1組を取り出すパターン

`elements S : Multiset A` を、S の各要素をちょうど1回含む多重集合とする。
順序は持たず、重複も持たない。この対象を `multiset A` で照合する。

```text
match elements S as multiset A with
| [] => ...
| $x :: #(σ x) :: $R => ...
exhaustive by pair_or_empty S σ h_closed h_no_fixed
```

`pair_or_empty` の主張は次の形である。

```text
lemma pair_or_empty
    (S : Finset A) (σ : A → A)
    (h_closed : ∀ x ∈ S, σ x ∈ S)
    (h_no_fixed : ∀ x ∈ S, σ x ≠ x) :
    elements S matches [] | $x :: #(σ x) :: $R
        as multiset A
```

この網羅性補題の証明は、S が空かどうかの場合分けで与えられる。
空なら第1のパターンにマッチする。空でなければ x ∈ S を一つ選ぶ。
h_closed から σ(x) ∈ S、h_no_fixed から σ(x) ≠ x が得られるため、
両方を1回ずつ取り出せる。ここでは σ²(x) = x は必要なく、
対合の性質は、取り出した残りに帰納仮定を適用する際に使う。

`exhaustive by` が使う証拠は、この空または1組という分解が必ず存在することを
保証する。探索を実行して要素を選ぶ場合には、A の等式を判定できることも必要になる。
命題としてのマッチ成立は、等式の証拠で記述する。

## 3. 第2の腕で受け取る値と証拠

第2の腕では x : A と R : Multiset A を受け取る。
さらに、マッチ成立の証拠と `elements S` の重複がないことから、次を得る。

\[
\mathrm{elements}(S)
=x::\sigma(x)::R.
\]

- x ∈ S、σ(x) ∈ S、および x ≠ σ(x)。
- R の要素に重複がないこと。
- x と σ(x) が R に含まれないこと。

T = support(R) と置く。**台集合（support）** は多重集合に含まれる値の集合である。
R に重複がないので、`elements T = R` が成立し、

\[
S=\{x,\sigma(x)\}\mathbin{\dot\cup}T,\qquad
|S|=2+|T|
\]

を得る。記号 $\dot\cup$ は、重なりのない集合の和を表す。
多重集合一般の `::` は出現を取り出すため、同じ値を2回取り出す場合もある。
この例で値の相異性と要素数の等式が得られる根拠は、S の各値を1回だけ列挙していることにある。

## 4. 残りに仮定が引き継がれることの証明

z ∈ T を取る。σ(z) ∈ S は h_closed から分かる。
σ(z) が取り除いた2要素のいずれでもないことを示す。

1. σ(z) = x と仮定すると、両辺に σ を適用し、h_invol を使って
   z = σ(x) を得る。これは σ(x) ∉ T と矛盾する。
2. σ(z) = σ(x) と仮定すると、同様に z = x を得る。
   これは x ∉ T と矛盾する。

したがって σ(z) ∈ T である。σ(σ(z)) = z と σ(z) ≠ z は、
T ⊆ S により元の仮定から引き継がれる。
これで、S と同じ三つの仮定が T について成立する。

この証明は、マッチから得た分解と元の仮定を使って行う。
残りが σ によって保たれるという事実を、`::` の意味論だけに含める必要はない。

## 5. 要素数についての帰納法

要素数がより小さい有限集合について同じ定理を仮定する、強い帰納法を使う。
帰納仮定は、S より要素数が小さいすべての有限集合と、三つの条件を満たす写像について用意する。

- 空の腕では |S| = 0 = 2·0 なので結論が成立する。
- 1組を取り出す腕では、§4 により T に帰納仮定を適用できる。
  §3 の |S| = 2 + |T| から |T| < |S| が得られ、再帰的な証明は停止する。

帰納仮定で得た自然数 k と等式 |T| = 2k を使い、

\[
|S|=2+|T|=2+2k=2(k+1)
\]

と結論する。主定理の結論は割り切りの命題であり、パターンは帰納法の各段階で
関係を持つ2要素と残りを取り出すために使われる。

具体的に S = {1,2,3,4,5,6} で、σ が 1 ↔ 4、2 ↔ 6、3 ↔ 5 と対応させる場合、
マッチで {1,4} と残り {2,3,5,6}、次に {2,6}、最後に {3,5} を取り出せる。
帰納法はこの3組から |S| = 2·3 という証拠を構成する。

## 6. 同じ分解を使う等式の証明

可換加法群 B（加法が結合的・可換で、0 と各値の逆元を持つ型）への重み
w : A → B が、すべての x ∈ S について w(σ(x)) = −w(x) を満たすとする。
同じパターンと帰納法で、

\[
\sum_{x\in S}w(x)=0
\]

を証明できる。空では和は0であり、1組を取り出す腕では分解の証拠から

\[
\sum_{z\in S}w(z)
=w(x)+w(\sigma(x))+\sum_{z\in T}w(z)
=w(x)-w(x)+0=0
\]

を得る。和を分解する一般的な補題、重みの仮定、帰納仮定を順に適用する。

例えば n ≥ 1 のとき、S を {1,…,n} のすべての部分集合からなる有限集合とし、
σ を「1が含まれていれば除き、含まれていなければ加える」操作とする。
これは固定点のない対合であり、w(U) = (−1)^|U| は対になる部分集合で符号が反転する。
したがって

\[
\sum_{U\subseteq\{1,\ldots,n\}}(-1)^{|U|}=0
\]

を得る。パターンは部分集合 U と σ(U) を取り出し、
符号が反転することは、1の追加・削除で要素数が1変わる補題で証明する。

## 7. 実装時に確定すること

- 多重集合の分解の証拠から、所属、重複の不在、台集合、要素数の関係を取り出す規則。
- 台集合への変換に伴う `elements (support R) = R` の証明と、その証拠の引き継ぎ。
- 要素数を用いた帰納法の型と、再帰的な証明で要素数が減ることの検査。
- `pair_or_empty` の主張と2腕のパターンを結び付ける `exhaustive by` の規則。
- 等式の証拠による値の置換と、有限和の分解補題の適用。

他の等式・帰納法での利用例は [証明の途中で使うパターン](pwl-proof-steps.md) にまとめる。
有限ケースでの残りの閉性や符号反転の確認は、同ファイルの §5 に記す。
